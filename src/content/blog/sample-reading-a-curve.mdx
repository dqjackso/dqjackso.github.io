This page is a sample. It shows inline mathematics, a displayed equation, a chart drawn from data, and a highlighted code block. It is not a piece of writing by Derek.

A short identity is enough to test type in the line: Euler's formula says that $e^\{i\pi\}+1=0$. The same circle of ideas, stretched into one wide line so a phone can scroll it, is a partial sum of reciprocals of squares.

$$
\sum_\{n=1\}^\{N\} \frac\{1\}\{n^\{2\}\} = \frac\{\pi^\{2\}\}\{6\} - \frac\{1\}\{N\} + \frac\{1\}\{2N^\{2\}\} - \frac\{1\}\{6N^\{3\}\} + \int_\{N\}^\{\infty\} \frac\{\lbrace t \rbrace - \frac\{1\}\{2\} + \frac\{1\}\{12t\}\}\{t^\{2\}\} \, dt + O(N^\{-4\})
$$

The figure uses an invented series, $y = \sin x + \frac\{x\}\{10\}$, only so the chart has something to draw. The points are computed, not measured. Hover a point for its coordinates. If the interactive chart cannot run, the same series stays as a static picture.

## A few lines of code

`partial_sum` adds the series the display equation describes. It is illustrative. The function is not a result from anyone's research.

```python
def partial_sum(n: int) -> float:
    """Sum of 1/k^2 for k = 1..n. A demo, not a numerical study."""
    total = 0.0
    for k in range(1, n + 1):
        total += 1.0 / k**2
    return total
```
